# LifeTrace 开发路线图

## M0：工程基线

- [x] 固定产品边界
- [x] 建立仓库结构
- [x] 记录架构与数据模型
- [x] 配置 Android SDK 与 Gradle Wrapper
- [x] 建立可重复的构建和测试命令

## M1：离线日记闭环

- [x] Room 数据库与迁移框架
- [x] 日记时间线
- [x] 新建与编辑日记
- [x] 1～9 张图片导入及缩略图
- [x] 时间和单次位置获取
- [x] 详情与删除
- [x] 进程重启和断网验收

完成标准：断网状态下能够可靠管理带图文、时间和位置的日记。

## M2：地图回看

- [x] 集成 MapLibre
- [x] 日记位置标记
- [x] 日期筛选
- [x] 轨迹线渲染与异常点提示

完成标准：能够使用高细节矢量底图按日记时间顺序查看带坐标记录的轨迹，并提示疑似定位跳变而不篡改原始数据。

## M3：智能后台轨迹

- [ ] 前台定位服务
- [ ] 分阶段权限引导
- [ ] 动态采样和漂移过滤
- [ ] 暂停、恢复与重启恢复
- [ ] 真机功耗和后台存活测试

## M4：安全同步

- [ ] Microsoft OAuth + Graph OneDrive 直连（最小 `Files.ReadWrite` 权限）
- [ ] 固定加密 ADR 与恢复密钥流程
- [ ] FastAPI 同步 API
- [ ] PostgreSQL 元数据存储
- [ ] 照片对象存储
- [ ] WorkManager 断点同步
- [ ] 冲突、删除墓碑和失败恢复

## M5：私有部署

- [ ] Docker Compose
- [ ] HTTPS 与密钥配置
- [ ] 数据库备份和恢复演练
- [ ] 服务健康检查
