# LifeTrace

LifeTrace 是一个面向个人使用的 Android 时空日记应用：用图片和文字记录日常，自动附加时间与位置，并在地图中按时间顺序呈现个人轨迹。

## 当前状态

当前版本为 v0.3.1：离线日记闭环已可用，并加入高清图片浏览、同篇照片左右滑动、年度活动热力图、日记坐标地图、按时间连接的日记轨迹线、疑似位置跳变提示和可选的 OneDrive/云盘文件夹镜像。后台连续轨迹、端到端加密和服务端同步仍在后续里程碑。

## 已确认的产品边界

- 单用户、个人使用
- Kotlin + Jetpack Compose 原生 Android 客户端
- 本地优先，联网后同步至私有云服务器
- 文字、1～9 张照片、时间戳和位置
- MapLibre 全球开源地图
- 智能全天后台轨迹
- 生物识别解锁
- 端到端加密
- 原图与缩略图并存，原图默认仅在 Wi-Fi 下同步

## 当前可用功能

- 断网新增、浏览、编辑和删除图文日记
- 最多 9 张照片，高清时间线缩略图与详情左右滑动
- 年度记录热力图
- MapLibre 日记位置标记、日期范围筛选和按时间连接的轨迹线
- 对明显不合理的相邻定位跳变给出提示，但保留原始坐标不做自动纠正
- 通过 Android 系统文件夹选择器连接 OneDrive/云盘目录
- 保存后立即镜像 JSON 与原图；删除时先归档到云端 LifeTrace/Trash

覆盖安装会保留应用私有数据；卸载会删除本地 Room 数据库和私有媒体目录，因此建议启用云盘镜像。云盘镜像是灾备副本，不等同于多设备实时同步。
