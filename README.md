# LifeTrace

LifeTrace 是一个面向个人使用的 Android 时空日记应用：用图片和文字记录日常，自动附加时间与位置，并在地图中按时间顺序呈现个人轨迹。

## 当前状态

当前版本为 v0.3.2：离线日记闭环已可用，并加入时间线卡片内直接左右滑图、详情原图全屏缩放、年度活动热力图、OpenFreeMap 矢量地图、日记轨迹线、主题切换，以及 `Documents/LifeTrace` 永久本地备份与重装恢复。后台连续轨迹、真正的 OneDrive OAuth 直连、端到端加密和服务端同步仍在后续里程碑。

## 已确认的产品边界

- 单用户、个人使用
- Kotlin + Jetpack Compose 原生 Android 客户端
- 本地优先，联网后同步至私有云服务器
- 文字、1～9 张照片、时间戳和位置
- MapLibre 全球开源地图
- 智能全天后台轨迹
- 生物识别解锁
- 端到端加密
- 原图与缩略图并存，原图默认仅在 Wi-Fi 下同步

## 当前可用功能

- 断网新增、浏览、编辑和删除图文日记
- 最多 9 张照片，时间线卡片内直接左右滑动，详情原图可点击全屏缩放
- 年度记录热力图
- MapLibre + OpenFreeMap 矢量地图、日期范围筛选和按时间连接的轨迹线
- 对明显不合理的相邻定位跳变给出提示，但保留原始坐标不做自动纠正
- 可切换跟随系统、经典白、薄荷绿和深色主题
- `Documents/LifeTrace` 永久本地备份：保存后镜像 JSON 与原图，卸载后目录仍保留，重装授权后自动扫描恢复
- Android 文件提供器“外部目录镜像”作为额外灾备；它不是 OneDrive 分享链接直连

从 v0.3.2 起项目使用固定 LifeTrace 签名链，后续同签名 APK 可覆盖安装。由于更早调试版本可能使用临时 debug 签名，迁移到 v0.3.2 时可能需要最后一次卸载；请先把旧版内容镜像到 Documents/Download 下的持久目录，再安装 v0.3.2 并启用永久本地备份。
